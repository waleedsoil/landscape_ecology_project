Adding the results

One fileOpen data/results.js and replace null with the plot mean, for example 'S-D': 412, or 'S-D': [412, 60] to show the spread between the loggers of that plot. The page updates on reload.
Which numbersUse the statistic named for each variable above (daytime mean, mean daily range, …). H1 is tested on clear days, so use clear-day means for the microclimate and say so in note.
What a tick means✓ means the measured difference has the predicted sign. It is not a significance test: each combination of aspect and forest type is one stand, so the four plots are compared, not replicated (see Methods).
Editing the predictionsThe predictions, the boxes and the arrows are lists at the top of assets/js/predictions.js. If you change a hypothesis, change its predictions there as well.
